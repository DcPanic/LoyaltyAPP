# Οδηγός: να δεις το app στο κινητό σου

Γραμμένος για κάποιον που δεν είναι προγραμματιστής, για **Windows**.
Στο τέλος θα σκανάρεις ένα QR code και θα έχεις το app στο κινητό σου —
**χωρίς να είσαι στο ίδιο WiFi** με τον υπολογιστή.

Συνολικός χρόνος την πρώτη φορά: περίπου 20 λεπτά. Μετά, μία εντολή.

---

## Βήμα 1 — Εγκατάστησε το Node.js

Είναι το πρόγραμμα που τρέχει τον κώδικα. Μία φορά και τελείωσε.

1. Πήγαινε στο <https://nodejs.org>
2. Κατέβασε την έκδοση που λέει **LTS** (η πράσινη, αριστερά)
3. Τρέξε το αρχείο που κατέβηκε → Next → Next → Install → Finish

## Βήμα 2 — Κατέβασε τον κώδικα

1. Άνοιξε το repo σου στο GitHub
2. Πράσινο κουμπί **Code** → **Download ZIP**
3. Βρες το ZIP στα Downloads, δεξί κλικ → **Extract All**
4. Βάλ' το σε απλή διαδρομή, π.χ. `C:\LoyaltyAPP`

> Ο φάκελος πρέπει να περιέχει αρχεία όπως `package.json` και φακέλους
> `apps`, `docs`. Αν βλέπεις άλλον φάκελο μέσα στον φάκελο, μπες μέσα του.

## Βήμα 3 — Άνοιξε το «μαύρο παράθυρο» στον φάκελο

1. Άνοιξε τον φάκελο `C:\LoyaltyAPP` στην Εξερεύνηση αρχείων
2. **Δεξί κλικ σε κενό σημείο** μέσα στον φάκελο → **Open in Terminal**
   (Windows 10: κράτα `Shift` + δεξί κλικ → *Open PowerShell window here*)

Θα ανοίξει ένα παράθυρο με κείμενο. Εκεί γράφεις τις εντολές.

> Σημείο ελέγχου: γράψε `node -v` και πάτα Enter. Αν δεις κάτι σαν `v22.x.x`,
> όλα καλά. Αν λέει ότι δεν αναγνωρίζεται, κλείσε το παράθυρο, άνοιξέ το ξανά
> και ξαναδοκίμασε.

## Βήμα 4 — Εγκατάσταση

Γράψε και πάτα Enter:

```
npm install
```

Θα τρέξει για 2–4 λεπτά και θα γράφει πολλά. Περίμενε να σταματήσει.

## Βήμα 5 — Φτιάξε τη βάση δεδομένων (δωρεάν, χωρίς εγκατάσταση)

Εδώ αποθηκεύονται πελάτες, σφραγίδες και δώρα. **Δεν εγκαθιστάς τίποτα** —
χρησιμοποιούμε μία δωρεάν βάση στο internet που δεν λήγει ποτέ.

1. Πήγαινε στο <https://neon.tech> → **Sign up** (με το Google σου)
2. **Create project** → όνομα ό,τι θες → περιοχή **Frankfurt** → Create
3. Θα σου δείξει το **connection string**: μια μακριά γραμμή που ξεκινά με
   `postgresql://`. Πάτα το κουμπί αντιγραφής.

## Βήμα 6 — Στήσιμο

Στο μαύρο παράθυρο:

```
npm run setup
```

Θα σε ρωτήσει `Database connection string:` → κάνε **δεξί κλικ** για επικόλληση
(στο PowerShell το δεξί κλικ επικολλά) → Enter.

Μετά ρωτάει αν θες δείγμα καφετέριας με πελάτες → πάτα Enter για ναι.

Όταν τελειώσει, θα σου δείξει:

```
Owner:   owner@coffeehouse.cy / CoffeeHouse123!
Barista: barista@coffeehouse.cy / CoffeeHouse123!
```

Αυτοί είναι οι λογαριασμοί για να μπεις.

## Βήμα 7 — Βάλε το Expo Go στο κινητό

Κατέβασε την εφαρμογή **Expo Go**:

- iPhone: App Store
- Android: Play Store

Δεν χρειάζεται λογαριασμός για αυτόν τον τρόπο.

## Βήμα 8 — Βγάλε το QR

Στο μαύρο παράθυρο:

```
npm run preview
```

Την πρώτη φορά κατεβάζει κάτι επιπλέον (μισό λεπτό). Θα δεις:

```
✓ API is running
✓ API is reachable at https://κάτι.trycloudflare.com

→ Starting Expo. Scan the QR code below with Expo Go.
  Your phone does NOT need to be on this Wi-Fi.
```

και μετά ένα **QR code** μέσα στο παράθυρο.

- **Android**: άνοιξε το Expo Go → *Scan QR code* → σκάναρε
- **iPhone**: άνοιξε την **Κάμερα** → σκάναρε → πάτα την ειδοποίηση

Το app ανοίγει. Μπες με `owner@coffeehouse.cy` / `CoffeeHouse123!`.

**Δοκίμασε: κλείσε το WiFi στο κινητό και άσε μόνο δεδομένα (4G/5G).**
Συνεχίζει να δουλεύει — αυτό είναι το tunnel.

## Για να σταματήσεις

Στο μαύρο παράθυρο πάτα `Ctrl + C`. Την επόμενη φορά τρέχεις μόνο
`npm run preview` — τα βήματα 1–6 δεν ξαναγίνονται.

---

## Τι να κάνεις αν κάτι πάει στραβά

**«npm δεν αναγνωρίζεται»**
Το Node δεν εγκαταστάθηκε ή το παράθυρο άνοιξε πριν την εγκατάσταση.
Κλείσε το παράθυρο, άνοιξέ το ξανά. Αν επιμένει, ξαναεγκατέστησε το Node.

**Τα Windows ρωτάνε για το τείχος προστασίας**
Πάτα **Allow / Να επιτραπεί** (αρκεί για ιδιωτικά δίκτυα).

**Το QR δεν φορτώνει στο κινητό**
Περίμενε μισό λεπτό και ξανασκάναρε — το tunnel θέλει λίγο να ζεσταθεί.
Αν επιμένει, `Ctrl + C` και ξανά `npm run preview`.

**Στο login λέει «Cannot reach the API»**
Έπεσε το tunnel. `Ctrl + C` και ξανά `npm run preview`.

**«The API did not start»**
Τρέξε πρώτα `npm run setup` — μάλλον δεν ολοκληρώθηκε το στήσιμο.

Αν κολλήσεις, βγάλε φωτογραφία την οθόνη και στείλ' τη — το λύνουμε.

---

## Ο ένας περιορισμός

Όσο τρέχει το `npm run preview`, **ο υπολογιστής σου είναι ο server**.
Αν τον κλείσεις ή κοιμηθεί, το app στο κινητό σταματά.

Για να δουλεύει και με κλειστό υπολογιστή, το app και η βάση πρέπει να ζουν
στο internet — αυτό είναι το επόμενο βήμα και περιγράφεται στο
[`DEPLOY.md`](DEPLOY.md). Δεν το χρειάζεσαι για να δεις και να δοκιμάσεις το app.

# Μέρος Β — Να δουλεύει ο Claude κατευθείαν στον υπολογιστή σου

Αντί να στέλνει ο Claude αλλαγές στο GitHub από το cloud, μπορεί να ανοίξει
τον φάκελο στον υπολογιστή σου, να δουλέψει εκεί και να κάνει push ο ίδιος.

## Τι χρειάζεται επιπλέον

1. **Git για Windows** — <https://git-scm.com/download/win> → τρέξε το αρχείο →
   Next σε όλα → Install. (Αυτό φέρνει και τη σύνδεση με το GitHub.)
2. **Node.js** — αν δεν το έκανες ήδη στο Μέρος Α.

## Βήμα 1 — Εγκατέστησε τον Claude Code

Άνοιξε ένα terminal (δεξί κλικ σε φάκελο → Open in Terminal) και γράψε:

```
npm install -g @anthropic-ai/claude-code
```

## Βήμα 2 — Κατέβασε τον κώδικα με git (ΟΧΙ με ZIP)

**Σημαντικό:** το ZIP δεν συνδέεται με το GitHub, άρα δεν μπορεί να κάνει push.
Χρειάζεται `git clone`.

Στο terminal, πήγαινε εκεί που θες να μπει ο φάκελος (π.χ. `cd C:\`) και:

```
git clone https://github.com/DcPanic/LoyaltyAPP.git
cd LoyaltyAPP
git checkout claude/intelligent-edison-xuhnwr
```

Την πρώτη φορά θα ανοίξει παράθυρο για να συνδεθείς στο GitHub — συνδέσου
με τον λογαριασμό σου. Αυτό γίνεται μία φορά.

> Αν είχες ήδη κατεβάσει ZIP, σβήσε εκείνον τον φάκελο και ξεκίνα με clone.

## Βήμα 3 — Άνοιξε τον Claude μέσα στον φάκελο

```
claude
```

Θα σου ζητήσει να συνδεθείς με τον λογαριασμό σου Claude. Μετά μιλάς κανονικά:

- «τρέξε npm install»
- «κάνε το στήσιμο με τη βάση»
- «βγάλε μου το QR για το κινητό»
- «κάνε commit και push τις αλλαγές»

Δεν χρειάζεται να θυμάσαι εντολές — τις τρέχει εκείνος.

## Βήμα 4 — Το πρώτο push

Πες του «κάνε commit και push». Αν είναι η πρώτη φορά, το Git θα ανοίξει
παράθυρο σύνδεσης με το GitHub. Συνδέσου και τελείωσε.

## Πράγματα που καλό είναι να ξέρεις

- **Πριν αρχίσεις δουλειά τοπικά**, πες του «κάνε pull πρώτα». Έτσι παίρνει
  ό,τι έχει αλλάξει από το cloud και δεν μπερδεύονται οι αλλαγές.
- **Μην δουλεύεις ταυτόχρονα** από το cloud και από τον υπολογιστή σου στα ίδια
  αρχεία — θα χρειαστεί να λύσετε συγκρούσεις μετά.
- **Οι κωδικοί δεν ανεβαίνουν ποτέ.** Τα αρχεία `.env` (με τη βάση και τα
  κλειδιά) είναι εξαιρεμένα από το git.
- Υπάρχει αρχείο `CLAUDE.md` στον φάκελο: το διαβάζει αυτόματα κάθε φορά και
  ξέρει το έργο, τις εντολές και ότι μιλάς ελληνικά.
